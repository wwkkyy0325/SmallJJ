# 验收流程

**优先真机。** 真机才是最终口径：dpi、字宽、安全区、厂商 ROM 行为只有手机上才准。
手机不在手上时（坏屏、送修、没电）退回模拟器，把能验的先验完，**等手机回来再补真机那一遍**。

模拟器口径：`emulator-5556`（AVD `SmallJJ`，API 35，arm64-v8a，1080×2400，density 420）。
和手机（OnePlus 6T，1080×2340，density 450）差两点：

- **密度 420 vs 450**：同一段文字在模拟器上略宽，胶囊、导航栏的像素尺寸差 1–2 px 属正常。
- **没有 OPPO 的 ROM 行为**：桌面长按快捷方式、小布语音、厂商省电策略只能在真机看。

模拟器能验的：卡片数值口径、红绿有没有、字号字族、导航栏位移、浮层位置和尺寸、
引导页文案、数据库落库、deep link 落库。

## 0. 环境（本机已就绪，不用重装）

| 东西 | 路径 |
|---|---|
| adb | `~/dev/android-sdk/platform-tools/adb` |
| flutter | `~/flutter/bin/flutter` |
| JDK（flutter 直接调会缺） | `~/dev/java/current` |

`adb` / `flutter` 不在 PATH 里，一步到位的做法是先 `source ~/dev/env.sh`——它一次把
`JAVA_HOME`、`flutter`、`adb`、`ANDROID_AVD_HOME`、`GRADLE_USER_HOME` 都摆好：

```bash
source ~/dev/env.sh
adb devices -l               # 真机一行 OnePlus 6T（1f9a34d3）；模拟器一行 emulator-5556
```

少了它 Gradle 会报 `Unable to locate a Java Runtime`：`flutter` 自己不认 JDK，只读环境变量。

模拟器没开时：`emulator -avd SmallJJ -no-snapshot-load &`（`emulator` 在
`~/dev/android-sdk/emulator/`，也由 `env.sh` 摆进 PATH）。

看不到设备 = 线没插 / 手机上没允许 USB 调试。手机端做一次：开发者选项 →
USB 调试打开 → 插线后手机上点「允许」。**别用无线调试**，本机 adb 只认 USB。

## 1. 装到手机（一条命令）

```bash
export JAVA_HOME="$HOME/dev/java/current"
"$HOME/flutter/bin/flutter" build apk --release --target-platform android-arm64
adb install -r build/app/outputs/flutter-apk/app-release.apk
# 模拟器同一句，只是多指定设备（也是 arm64，包通用）：
adb -s emulator-5556 install -r build/app/outputs/flutter-apk/app-release.apk
```

要点：

- **装 release 包，不装 debug 包。** debug 包在同机冷启动 ≈3.5 s、release ≈0.39 s，
  差 9 倍，体感完全不同。
- **签名钥匙钉在项目里**：`android/app/build.gradle.kts` 的 `signingConfigs.app` 指向
  `android/app/signing/smalljj.jks`（alias `androiddebugkey`，密码 `android`，自用不上架），
  debug / profile / release 全用这一把，文件已入库。所以 `adb install -r` 能直接覆盖，
  **数据库不会丢**。
- 别让环境变量决定签名：曾经因为 `ANDROID_SDK_HOME` 指到 `~/dev/android-avd`，Gradle
  在那儿另生成了一把 debug 钥匙，于是手机上报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`，
  只能卸载（数据一起没）。换钥匙也是一样的后果——这块之后不能换。
- `--target-platform android-arm64` 只编手机要的那一份，比默认的胖包快。OnePlus 6T 是 arm64。
- 换机器（或换上 arm64 以外设备）才需要 `--target-platform android-arm`。

## 2. 验收看什么（当前这轮：没有目标 / 预算，卡片只报数）

冷启动到「今天」页，逐项过：

1. **热量卡**：左上「今日摄入」、右上「估算消耗 1953」、大数字是今天吃进去的
   kcal，条子按「已摄入 / 估算消耗」填，下面一行只写方向——「比估算消耗少 1674 kcal」。
   **没有红字、没有绿字、没有「缺口 / 超出 / 还剩多少」**；刻意吃到超过估算消耗，
   也只变成「比估算消耗多 X kcal」，条子满格但不变色。
2. **「我的」页**：身体资料只有「出生年 / 身高 / 日常活动量」，**没有目标、没有目标体重、
   没有每周变化**，卡片里不留空档。
3. **饮食页**：顶部「279 kcal + 估算消耗 1953」，三条宏量写的是「21 g · 30%」（占今天热量），
   不是「达标 70%」。
4. **体重页**：没有目标线、没有「预算按 … 计算」这句话。
5. **长按桌面图标**：四条快捷方式，第三条叫「今天吃了多少」（原来叫「今天还能吃多少」）。
6. **体重卡两颗胶囊**：左「现在 16:04」、右「66.00 kg」——同一字号、同一字重、
   同一字族，等高、缝 8 dp、和保存键左右对齐；点开各是一屏滚轮，滚到哪格就是哪格。
7. **底部导航栏**：点任意一横、进出浮层时不许上下位移；键盘弹出时也不许动。
8. **引导页页脚**（只有新装机才看得到）：一句「活动量先按「轻度」算，之后在「我的」里改，
   估算消耗会跟着重算。」——**不许再出现「目标按减脂 0.5 kg/周」**，功能已经没有了。

任何一处字号和别处不一样，就把截图和位置告诉我——不要再各自 `copyWith(fontSize:)`，
改 `lib/theme/tokens.dart` 里的令牌（`test/typography_test.dart` 会拦住私自改字号）。

## 3. 出问题时怎么取证

```bash
ADB="$HOME/dev/android-sdk/platform-tools/adb"

# 崩溃 / 异常栈
"$ADB" logcat -d -t 400 | grep -iE 'flutter|smalljj|AndroidRuntime' | tail -60

# 当前页截图（直接拉成 png）
"$ADB" exec-out screencap -p > /tmp/sj_phone.png
```

```bash
# 数据库导出（真机）：release 包不可调试，run-as 会报 "package not debuggable"。
# 因为 debug 与 release 现在同一把钥匙，先 -r 装 debug 包（数据不动）、导完再装回 release。
ADB="$HOME/dev/android-sdk/platform-tools/adb"
export JAVA_HOME="$HOME/dev/java/current"
"$HOME/flutter/bin/flutter" build apk --debug
"$ADB" install -r build/app/outputs/flutter-apk/app-debug.apk
# 打开一次 App，让进程起来后：
"$ADB" shell run-as com.smalljj.health_app \
  cp /data/data/com.smalljj.health_app/databases/smalljj.db /sdcard/smalljj.db
"$ADB" pull /sdcard/smalljj.db /tmp/sj_phone.db      # 连同 -shm / -wal 一起读
"$ADB" install -r build/app/outputs/flutter-apk/app-release.apk

# 模拟器上不用换 debug 包：emulator-5556 的 adbd 已经是 root，直接拷库
# （App 跑过一次、文件存在即可；库在 files/ 下，不是 databases/）
"$ADB" shell 'cp /data/data/com.smalljj.health_app/files/smalljj.db /data/local/tmp/e.db
               cp /data/data/com.smalljj.health_app/files/smalljj.db-wal /data/local/tmp/e.db-wal
               chmod 644 /data/local/tmp/e.db*'
"$ADB" pull /data/local/tmp/e.db /tmp/sj_emu.db
"$ADB" pull /data/local/tmp/e.db-wal /tmp/sj_emu.db-wal
sqlite3 /tmp/sj_emu.db 'select * from meal_item;'   # 必须和 -wal 放同一目录再查
```

```bash
# 链接入口（带数值就直接落库，不弹表单）
"$ADB" shell am start -a android.intent.action.VIEW -d "smalljj://weight?kg=59.82&time=08:00"
"$ADB" shell am start -a android.intent.action.VIEW -d "smalljj://query?what=intake"
# 老写法 what=budget 仍然当别名接受，不会报错，也不会提「预算」
```
